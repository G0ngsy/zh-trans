# Hanyu Lens 업데이트 — poly

기준일: 2026-11-06
기준 코드: poly / 5b461ac

## 업데이트 내용
- 중국어 입력창 안내를 `중국어를 입력하세요`로 간소화했습니다.
- 두 백엔드 진입점의 실시간 OCR 처리를 `backend/realtime_ocr.py`로 공통화했습니다. 각 API의 병음 구분 및 line_id 응답 형식은 유지합니다.
- Ollama 응답의 HTTP 오류를 확인하고, 단어 분석 실패 시 로그를 기록하도록 보완했습니다.
- 텍스트 번역 실패 시 오류를 기록하고 HTTP 503 오류 응답을 반환하도록 보완했습니다.
- 백엔드 의존성 버전을 requirements.txt에 명시했습니다.
- 기존 문서 정리 변경을 포함합니다. frontend/README.md 삭제도 브랜치 차이에 포함됩니다.

## 검증 결과
- 최신 origin/main과 충돌 없이 통합 가능한 것을 확인했습니다.
- 미커밋 변경을 제외한 poly 사본에서 프론트엔드 전체 빌드와 ESLint 검사를 통과했습니다.
- 변경된 백엔드 Python 파일 3개의 문법 검사를 통과했습니다.
- 실제 OCR 모델 실행 및 외부 번역 API를 포함한 통합 검증은 수행하지 않았습니다.

## 포함 범위와 남은 사항
- 로컬의 미커밋 디자인 개편, 신규 디자인 자산 및 테스트 파일은 이번 업데이트에 포함하지 않습니다.
- Hugging Face Space는 별도 저장소입니다. Dockerfile 모델 사전 다운로드 및 pyclipper import 순서 변경의 적용·복구 여부는 확인되지 않았습니다.
- 장애 원인과 조치 경과는 troubleshooting.md에 기록했습니다.
- 이전 로컬 빌드 실패는 이번 격리된 커밋 사본에서는 재현되지 않았습니다. 로컬 미커밋 변경 상태의 빌드 문제는 별도 확인이 필요합니다.
